# GitHub Portfolio Sample — Abdurrahman Sani Awwalu

A simple, responsive portfolio starter for an aspiring SQL / database developer. It includes a personal portfolio website and two beginner MySQL projects.

## Included
- `index.html` — portfolio homepage
- `style.css` — responsive dark theme
- `projects/school-database.sql` — student database practice
- `projects/sales-analysis.sql` — sales summaries with `GROUP BY` and aggregation

## Customize before publishing
1. Open `index.html` and edit your introduction, skills, project descriptions, and contact details.
2. Replace `https://github.com/your-username` with your real GitHub profile URL.
3. Review the sample names and data in the SQL files. They are fictional demo records.
4. Add links to your real repositories once you upload the projects.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a public repository on GitHub (for example, `my-portfolio`).
2. Upload the contents of this folder to the repository's root. Make sure `index.html` is at the root.
3. On GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish, then open the URL shown in Settings → Pages.
